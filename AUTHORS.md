## Sobre este proyecto

Analista IA es una solución desarrollada originalmente por Emilson Oviedo Cardona
para una evaluación técnica de Analista IA. La prueba pedía construir un sistema
que priorizara leads comerciales a partir de datos de CRM y conversaciones de
WhatsApp, usando IA para extraer señales estructuradas y un scoring determinista
y explicable.

La arquitectura, el código, la documentación y las decisiones técnicas de este
repositorio fueron desarrollados originalmente para ese proyecto.
